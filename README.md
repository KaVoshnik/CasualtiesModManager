# Casualties Mod Manager

Менеджер модов для Casualties: Unknown (демо) на базе BepInEx 5.

## Сборка
Нужен .NET 8 SDK (Windows).

    dotnet run
    dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true

Готовый exe окажется в `bin/Release/net8.0-windows/win-x64/publish/`.

## Как пользоваться
1. Менеджер сам ищет игру в библиотеках Steam. Если не нашёл, нажми «Папка игры…».
2. «Установить BepInEx» скачивает BepInEx 5.4.23.4 (win_x64) с GitHub и распаковывает в папку игры.
   Один раз запусти игру, чтобы BepInEx создал свои папки.
3. Перетащи `.dll` или `.zip` мода в окно. Мод копируется в библиотеку и ставится в игру.
4. Галочка включает или выключает мод (файлы убираются из игры и возвращаются обратно).
5. «Экспорт сборки…» делает один файл `.cumods` со всеми модами, друг открывает его через «Импорт сборки…».

## Язык
Интерфейс по умолчанию английский. Русский включается в настройках (значок шестерёнки в заголовке окна), применяется сразу и запоминается.

## Каталог Nexus Mods
Вкладка «Nexus» в главном окне показывает каталог модов Casualties: Unknown с nexusmods.com: поиск, сортировка (популярные, новые, обновлённые, по лайкам), «Показать ещё» и установка в один клик. Установленный мод запоминает источник, и «Обновления» находит новые версии на Nexus.

1. При первом открытии вставь личный API-ключ: nexusmods.com → профиль → Site preferences → API Keys → Personal API Key. Ключ лежит только в `%AppData%\CasualtiesModManager\settings.json` и в сборки `.cumods` не попадает.
2. **Premium:** «Установить» скачивает и ставит мод сразу.
3. **Бесплатный аккаунт:** Nexus не отдаёт файл через API без перехода на сайт. «Установить» открывает страницу мода, там нужно нажать «Slow download» (или «Mod manager download»). Менеджер получит ссылку `nxm://` и сам скачает и поставит мод. Для этого включи плашку «Приём nxm-ссылок» на вкладке Nexus.
   - Это делает менеджер обработчиком `nxm://` для текущего пользователя Windows (раздел реестра `HKCU\Software\Classes\nxm`). Пока приём включён, Vortex / Mod Organizer ссылки не получают. Выключишь плашку, и прежний обработчик вернётся.
   - Приём работает только у собранного `.exe`, не у `dotnet run`. Ссылки на другие игры и коллекции менеджер отклоняет.
4. Без приёма nxm тоже можно: скачай `.zip` на сайте и перетащи в окно менеджера.
5. Мод, у которого файл не `.zip`/`.dll` (например `.7z`), менеджер не распакует. Он скажет об этом, и такой мод нужно поставить вручную.
6. Мод с Nexus можно добавить и кнопкой «По ссылке», вставив адрес страницы мода.

Ключ нужен для каждого запроса к Nexus. Личный ключ подходит для своего пользования; если будешь раздавать менеджер другим людям, Nexus требует зарегистрировать приложение у них (api-acceptable-use-policy).

## Как раскладываются файлы
- В zip есть папка `BepInEx/`: содержимое идёт от корня игры.
- В zip верхний уровень `plugins/` или `config/`: кладётся внутрь `BepInEx/`.
- Иначе (одиночный `.dll` или zip в стиле «распакуй в plugins»): всё идёт в `BepInEx/plugins/`.

Данные менеджера лежат в `%AppData%\CasualtiesModManager`.

## Примечания
- Если в пути к игре есть не-ASCII символы, BepInEx может не загрузить моды. Менеджер предупредит.
- Менеджер не проверяет моды на безопасность: ставь только то, чему доверяешь.
